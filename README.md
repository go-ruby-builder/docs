# go-ruby-builder/docs

Versioned documentation for [go-ruby-builder](https://github.com/go-ruby-builder), built with
[MkDocs Material](https://squidfunk.github.io/mkdocs-material/) and versioned with
[mike](https://github.com/jimporter/mike). Served at <https://go-ruby-builder.github.io/docs/>.

## Local preview

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
mkdocs serve
```
